# 🧾 User & Post API System

Node.js + MongoDB 기반의 사용자 인증 및 게시글 API 백엔드 시스템  
Version: In Development (시작일: 2023-12-05)

---

## 📌 프로젝트 소개

이 프로젝트는 **회원가입 / 로그인 / 이메일 인증 / 마이페이지 / 게시글 CRUD / 오류 처리** 등 웹 서비스의 핵심 백엔드 기능을 통합하여 구현한 API 서버입니다.  
MongoDB를 기반으로 유저 데이터 및 게시글 관리를 수행하며, 인증은 세션 기반으로 구현되어 있습니다.
